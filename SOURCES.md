# Sources, field meanings and accepted design choices

Read with PROCEDURE.md. This file is the reference both the proposer and the verifier work from. Changes to it are system changes and need Andrzej's merge.

## Fields in country-check-data.json
- `countries` (keyed by map country name): `n` display name; `cpi` / `prev` World Bank Control of Corruption governance score 0-100, latest and prior year (the name "cpi" is historical; it is NOT Transparency International); `fatf` "black" or "grey" (absent = not listed); `fto` "y" identified, "n" none identified, "a" or absent = "Not covered"; `ftog` FTO group names; `us` "c" comprehensive U.S. sanctions, "t" targeted country program; `usp` [program name, OFAC URL]; `eu` EU country-based restrictive measures, including EU implementations of UN regimes; `un` UN Security Council regimes; `uk`, `ca`, `ch`, `au` lists of [name, official URL] (UK regimes including the UK arms embargo on mainland China and Hong Kong; Canadian regulations under SEMA and the UN Act; Swiss ordinances under the Embargo Act, English titles are Paragon's renderings of the German titles, linked to Fedlex; Australian sanctions frameworks, DFAT); `iso2` / `iso3` codes.
- `fto_listings`: each FTO name and the other bodies that list it (EU, EU military wing, UK, UN, Canada, Australia). `fto_listing_evidence`: the pattern that finds each label on the official list.
- `fatf_evaluations`: latest FATF mutual evaluation per jurisdiction, [evaluation date YYYY-MM, latest ratings update YYYY-MM, assessment body]. The page shows only date and body, never ratings (licensing).
- `crt_links`: map country name to the slug of its page in the State Department's Country Reports on Terrorism 2024 (https://www.state.gov/reports/country-reports-on-terrorism-2024/<slug>/).
- `meta.page`: the page's as-of text and each view's "checked" date (see PROCEDURE.md).

## Where to check (the cloud shell reaches the World Bank API, gov.uk, publicsafety.gc.ca, nationalsecurity.gov.au, the UN XML, the EU financial sanctions XML, the EU Sanctions Map API, the Federal Register API and OpenSanctions; state.gov, dfat.gov.au and fatf-gafi.org may refuse the shell, so use web fetch for those)
- **U.S. FTO designations**: Federal Register API is primary (documents with agency state-department and term "Foreign Terrorist Organization" since the last check, plus https://www.federalregister.gov/api/v1/public-inspection-documents/current.json); also https://www.state.gov/foreign-terrorist-organizations . Watch alternate names (Ansarallah = the Houthis). For a newly designated group, presence in a country comes only from State Department reporting (designation notice, Country Reports, "Areas of Operation"); every such change is strict.
- **Other bodies' labels** (rule: a label applies only where the group itself, or a name the listing expressly includes, is listed; parents, factions and affiliates do not count; EU = Common Position 931 list including the 2026 IRGC listing, EU ISIL/Al-Qaida sanctions, or any UN listing): Canada https://www.publicsafety.gc.ca/cnt/ntnl-scrt/cntr-trrrsm/lstd-ntts/crrnt-lstd-ntts-en.aspx ; Australia https://www.nationalsecurity.gov.au/what-australia-is-doing/terrorist-organisations/listed-terrorist-organisations ; UK https://www.gov.uk/government/publications/proscribed-terror-groups-or-organisations--2/proscribed-terrorist-groups-or-organisations-accessible-version ; UN https://scsanctions.un.org/resources/xml/en/consolidated.xml ; EU https://webgate.ec.europa.eu/fsd/fsf/public/files/xmlFullSanctionsList_1_1/content?token=dG9rZW4tMjAxNw (programmes TERR, TAQA, EUAQ, HAM; the IRGC terrorist listing may appear only under IRN).
- **State Department country report links**: the Country Reports on Terrorism 2024 index https://www.state.gov/reports/country-reports-on-terrorism-2024/ ; report to Andrzej if a 2025 edition is published (the FTO view and links would need rework, which is a system change).
- **OFAC**: https://ofac.treasury.gov/sanctions-programs-and-country-information (comprehensive embargoes currently Cuba, Iran, North Korea, plus the occupied Ukraine regions note).
- **UK**: https://www.gov.uk/government/collections/uk-sanctions-regimes-under-the-sanctions-act
- **Canada**: https://www.international.gc.ca/world-monde/international_relations-relations_internationales/sanctions/current-actuelles.aspx?lang=eng
- **Switzerland**: https://www.seco.admin.ch/de/sanktionsverordnungen (German); Fedlex links.
- **Australia**: https://www.dfat.gov.au/international-relations/security/sanctions/sanctions-regimes-currently-implemented-under-australian-sanction-law ; every au link points to its own framework page under /sanctions/sanctions-regimes/.
- **EU**: EU Sanctions Map (https://www.sanctionsmap.eu , API /api/v1/regime). Include EU regimes implementing UN regimes; exclude the legacy "prohibiting the satisfying of certain claims" regimes.
- **UN Security Council regimes**: https://main.un.org/securitycouncil/en/sanctions/information
- **FATF lists**: https://www.fatf-gafi.org/en/countries/black-and-grey-lists.html and the plenary outcome publications. List changes are strict (two sources: the outcomes publication and the list publication).
- **FATF mutual evaluations**: the consolidated assessment ratings tables (FATF blocks cloud downloads; a monthly task on Andrzej's computer reads them) and mutual evaluation reports published since.
- **World Bank WGI**: only when source 3's lastupdated (https://api.worldbank.org/v2/sources?format=json) is later than the date in meta.as_of.cpi; compare GOV_WGI_CC.SC rounded, by iso3.
- **Outside tie-breaker**: OpenSanctions https://data.opensanctions.org/datasets/latest/us_state_terrorist_orgs/targets.simple.csv

## Accepted design choices (not errors; do not propose changes)
Israel and Palestine share one FTO entry and one State Department link; Taiwan is scored; Croatia and Slovenia sit under OFAC's Balkans program; the Basel AML Index and Transparency International's CPI are deliberately not shown; FATF ratings are deliberately not reproduced; U.S. territories and similar dependencies without their own FATF evaluation show "no published FATF evaluation"; Australia's former Federal Republic of Yugoslavia framework and the EU "satisfying of claims" regimes are deliberately not mapped to a country; thematic sanctions regimes are excluded; the U.S. Ethiopia-related program ended in September 2026; the IRGC is on Australia's state-sponsor list, not its terrorist organisation list, so no Australia label; La Nueva Familia Michoacana and Los Viagras are named by Canada only as factions of other listed entities, so no Canada label; Cuba, Iran and Syria have no Country Reports on Terrorism country page (State Sponsors chapter), so no State Department link shows for them. Groups listed only under a non-terrorism regime (for example the UN Haiti regime) get no label.
